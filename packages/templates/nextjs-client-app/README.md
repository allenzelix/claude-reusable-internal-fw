# nextjs-client-app template

Copy this folder into `clients/<name>/app` when onboarding a new client, rename its `package.json` `name` field to `<name>-app`, add a sibling `clients/<name>/config.ts` (see `clients/_example/config.ts`), and fill in `.env.local` from `.env.example` — see the `client-onboarding` skill for the full walkthrough.
